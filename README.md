# JWMaps

Minecraft-inspired real-world maps for Android and Android Auto.

This project is in development. The first release targets a map and nearby-places explorer with verified APK and map-data updates. Full turn-by-turn navigation, Waze traffic integration and a verified real-car installation are not yet delivered.

- [First-release specification](docs/SPEC.md)
- [Releases](https://github.com/wallajl/JWMaps/releases)

The map uses OpenStreetMap data with attribution. JWMaps is independent of Mojang, Microsoft, Google, Waze and Ford.
